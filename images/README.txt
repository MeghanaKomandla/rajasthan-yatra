Put your own photos in this folder, for example:  images/amer-fort.jpg

Then use the photo in either of two ways:
1. On the website, press "Change photo" (or "+ Add a place") and type:  images/amer-fort.jpg
2. Or in js/data.js add {img:"images/amer-fort.jpg"} as the last item of a place, e.g.
   ["Amer Fort","fort",11,"3 hrs","Hilltop palace-fort ...", {img:"images/amer-fort.jpg"}]

Keep photos under about 300 KB each (1200 px wide JPG is plenty) so the site loads fast.
Use lowercase file names with no spaces.
